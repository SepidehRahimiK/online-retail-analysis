# Online Retail Data Analysis

## Project Overview
This project focuses on data analysis of online retail
transactions to explore sales patterns and customer
purchasing behavior.

## Objectives
- Explore the dataset
- Clean and preprocess the data
- Analyze data distributions
- Perform statistical analysis
- Visualize sales patterns

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

## Installation

Install the required libraries:

pip install -r requirements.txt

## Notebook

Open Online_Retail_Analysis_v2.ipynb
to explore the complete analysis.
